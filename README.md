## 下单前必须核验的六件事

这六项的共同点是，销售页不会主动告诉你，但每一项都能让你在使用中付出代价。

### 1. 要测试 IP，自己跑双向 MTR

客服给不给测试 IP，本身就是个信号。拿到之后从你的办公网、从你的主要访客所在的运营商各测一遍，去程和回程分别记录。只看 ping 值不够，晚高峰丢包才最影响体验。测试结果截图存下来，将来出现线路变更时这是你唯一的对照物。

### 2. 带宽是独享还是共享

“10M 带宽”这句话在共享带宽和独享带宽下完全是两回事。共享意味着同一台物理机上的其他用户跑满时，你的实际吞吐会掉。LuckVM 在 FAQ 里明确写自己提供的是独享带宽、不限流量、高峰期不限速，这种写清楚的商家相对少见。LightLayer 这一项建议在下单前用工单问明，问法和记录都留着。

### 3. 端口上限不等于保底吞吐

1Gbps 端口说的是网卡上限，不是持续保证的吞吐量。这个区别在低价套餐上尤其明显：端口写着 20M，实际能稳定跑多少要看上游带宽池和同宿主机邻居的用量。判断方法是买之前问一句“这个套餐的带宽是保底还是峰值”，买了之后用实际传输测一遍。

### 4. Windows 授权费算不算在价内

LightLayer 支持 Windows 和 Linux。Linux 各发行版通常免费，Windows Server 的授权在多数香港商家那里是单独计费的，LuckVM 明码标出约 US$8–15/月，这笔钱有时比主机本身还贵。如果你打算用远程桌面跑业务软件，把授权费算进总成本再比较，别只看主机标价。

### 5. 退款条款比退款宣传语重要

“支持退款”和“你能退款”是两件事。要看的是退款期限、流量是否扣费、退款去向、以及哪些产品被排除在外。MatrixIDC 公布的口径是新购 VPS 24 小时内全退，超过 24 小时、7 天内按天扣费，并且明确说明不适用于所有订单。UCloud 的香港精品原生 IP 轻量云主机则写得更直接：为保证 IP 纯净度、防止 IP 池污染，开通后不退费。IP 类产品的不退款条款在行业里真实存在，签单前翻一遍你买的那一款的例外清单。

## 按场景选配置：三种常见需求

**纯内容站和个人博客。** 1 核 1G、10M 不限流量这一档就是为这种负载准备的。文章页、图片经过压缩、套一层 CDN，日常并发很低。买更大的配置是浪费。

**外贸展示站和小型 WooCommerce。** 内存是第一个瓶颈，PHP 进程加上 MySQL 会把 1G 吃满。直接上 2G 起，CPU 核心数两个就够。带宽反而不用太紧张，商品页的图片做好压缩比加带宽更有效。

**下载站、视频和流媒体中转。** 这类业务要盯的是流量额度，不是带宽数字。20M 加 500G 的档，跑满带宽大约 7 小时就能把额度用完。这类需求更适合选不限流量的方案，同时确认商家对持续大流量的态度。

**开发测试环境。** 先用短周期验证系统镜像、依赖安装和实际访问，别一上来就年付。要注意的是低价套餐通常带使用边界，MatrixIDC 的产品页就明确禁止长期满 CPU 业务，压测和编译这类负载要提前确认规则。

## 常见问题

**香港云服务器需要备案吗？**
不需要。香港节点不受内地 ICP 备案约束，开通即可绑定域名上线。这也是很多人选香港而不是内地节点的直接原因。

**5M 带宽能撑多少访客？**
这个问题没有通用答案，因为缺了页面大小和并发数两个必要条件。实用的算法是：记录一次典型页面加载需要传输多少数据，估算高峰时段同时有多少次这样的请求，两者相乘再和带宽换算比对。图片多的站先把图片和缓存处理好，收益比加带宽大。

**能装 Windows 吗？**
可以，LightLayer 支持 Windows 和 Linux。Windows Server 的授权费用是否包含在套餐价内要单独确认，这笔费用按月计可能达到 US$8–15。

**24 小时退款人人适用吗？**
不是。退款条款通常带例外，定制硬件、GPU 实例、原生 IP 类产品的规则往往不同。买之前问一句“我这个产品适不适用首购退款”，比事后争论有用。

**香港、新加坡、日本怎么选？**
看你的访客在哪。主要用户在内地，香港延迟最低；面向东南亚，新加坡更近；面向日韩，日本节点更优。三个都想要，就得多地部署，成本随之上升。
